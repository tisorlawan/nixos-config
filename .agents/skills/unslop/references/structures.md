# Structures to avoid

Adapted from stop-slop's `references/structures.md`. Where stop-slop and the pstack `unslop` skill disagree, this file follows `unslop`.

## Binary contrasts

These create false drama. State the point directly: "The problem is Y." Drop the negation.

| Pattern | Problem |
|---------|---------|
| "Not because X. Because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup and reveal |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y.", "isn't X, it's Y" | Mechanical contrast |
| "stops being X and starts being Y" | False transformation arc |
| "doesn't mean X, but actually Y" | Negation, then assertion |
| "is about X but not Y" | False distinction |
| "not just X but also Y" | Additive hedge |

## Negative listing

Listing what something is not before revealing what it is. State the last item.

| Pattern | Problem |
|---------|---------|
| "Not a X... Not a Y... A Z." | Buildup through negation |
| "It wasn't X. It wasn't Y. It was Z." | The same structure in past tense |

## Dramatic fragmentation

Fragments for emphasis read as manufactured profundity. Write complete sentences and trust the content.

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the [thing]." | Performative simplicity |
| "X. And Y. And Z." | Staccato drama |
| "This unlocks something. [Word]." | Artificial revelation |

## Rhetorical setups

These announce an insight instead of delivering it. Make the point.

| Pattern | Problem |
|---------|---------|
| "What if [reframe]?" | Socratic posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending prompt |
| "And that's okay." | Unnecessary permission |

## Formulaic constructions

| Pattern | Problem |
|---------|---------|
| "By the time X, I was Y." | Narrative template |
| "X that isn't Y" | Indirect. Say "X is broken". |

## False agency

Inanimate things get human verbs, which avoids naming the actor. A person does something to make each of these happen. Name that person. If no specific person fits, use "you".

| Pattern | Problem |
|---------|---------|
| "a complaint becomes a fix" | The complaint did nothing. Someone fixed it. |
| "a bet lives or dies in days" | Someone kills the project or ships it. |
| "the decision emerges" | Someone decides. |
| "the culture shifts" | People change behavior. |
| "the conversation moves toward" | Someone steers it. |
| "the data tells us" | Someone reads the data and draws a conclusion. |
| "the market rewards" | Buyers pay for things. |

## Narrator from a distance

Floating above the scene instead of putting the reader in it.

| Pattern | Problem |
|---------|---------|
| "Nobody designed this." | Disembodied observation |
| "This happens because..." | Lecturer voice |
| "This is why..." | The same |
| "People tend to..." | Armchair sociologist |

"You don't sit down one day and decide to..." beats "Nobody designed this."

## Passive voice

Passive voice hides the actor. Find the actor and put them at the front of the sentence. Passive is fine when the actor is unknown or does not matter.

| Pattern | Fix |
|---------|-----|
| "X was created" | Name who created it |
| "It is believed that" | Name who believes it |
| "Mistakes were made" | Name who made them |
| "The decision was reached" | Name who decided |

## Sentence starters

A Wh- opener is a problem when it teases the point: "What makes this hard is..." becomes "The constraint is...", or better, the constraint itself. A plain question in a FAQ or a heading is fine.

| Pattern | Fix |
|---------|-----|
| A sentence that teases the point with What, When, Where, Why, or How | Lead with the subject or the verb |
| A paragraph that starts with "So" | Start with the content |
| A sentence that starts with "Look," | Remove it |

## Rhythm

| Pattern | Fix |
|---------|-----|
| Forced three-item lists | Use the natural number. Two often beat three. |
| A question answered immediately | Cut the question or let it stand |
| Every paragraph ends on a punchy line | Vary the endings |
| Em dashes | Remove them. Use a comma or a period. |
| Stacked short sentences | Combine them or vary the length |
| "Not always. Not perfectly." | Hedging disguised as reassurance |

## Lazy extremes

"every", "always", "never", "everyone", "nobody" claim false authority. Use a count, a case, or a named group.
