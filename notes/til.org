* AI Stuff
** Mamba => alternative to transformer attention
- In a normal Transformer, attention lets every token look back at previous tokens:
- This is powerful, but maintaining that history requires a KV cache. As context grows, the KV cache grows too.
- Mamba uses a different idea called a State Space Model (SSM).
- Mamba is like a GPU-optimized running memory that continuously compresses the important information
  from previous tokens into a fixed-size hidden state, instead of attention repeatedly looking
  back through the whole token history.
