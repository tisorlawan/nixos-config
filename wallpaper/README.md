# Wallpapers

hyprpaper shows a slideshow of the folder that the link `current` points to.
`~/.scripts/theme-colors` sets the link for the selected theme and mode, then restarts hyprpaper. Git ignores the link.

- `<theme>-<mode>/` holds wallpapers for one theme and mode.
  `everforest-dark/` holds Omarchy's Everforest background (https://github.com/basecamp/omarchy, `themes/everforest/backgrounds/`).
  `everforest-light/` holds `fog_forest_1.png` and `fog_forest_alt_1.png` from https://github.com/Gurjaka/Everforest-Wallpapers (MIT-0), converted to WebP.
- `dark/` and `light/` are the fallbacks for every other theme and mode.
  They come from https://www.wallpaperflare.com/.
